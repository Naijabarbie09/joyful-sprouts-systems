## Pushback recorded

A UPS filing concerns the import entry. Under CPSC eFiling (mandatory since Jul 8, 2026), a broker can file a "disclaim": Disclaim A says no rule requires a certificate for the product; Disclaim B covers cases where CPSC is not requiring the data. Broker guidance says these affect entry processing only and the importer stays responsible for certification. CPSC's own guidance lists children's clothing as needing a certificate. So the filing is unlikely to settle the selling question, and if it stated that no certificate is required for baby apparel it should be reviewed.

A real route to lighter requirements exists: CPSC small batch manufacturer registration. Registered firms still issue a certificate, but for "Group B" rules it need not rest on third-party lab testing. Whether apparel flammability, sleepwear and lead content are Group B is NOT VERIFIED here and must be read from CPSC's list.

Sources: CPSC CPC FAQ and small batch pages; CPSC disclaim guidance (Sep 28, 2026); UPS and broker eFiling pages. Read via search extracts, not full pages.
