## Open before signing

1. **Snap metal in writing, with the grade.** The stainless determination excludes one leaded grade (303Pb), so the grade matters.
2. **"Nickel-free" and "stainless" need reconciling.** The common stainless grades (304, 316) contain nickel. Nickel-free stainless grades exist (for example 430) and are strongly magnetic. Ask the supplier which grade it is. A quick home check: if a magnet does not stick firmly to the snaps, they are either a stainless grade that contains nickel or not stainless at all, and one of the two claims is wrong.
3. **Neck label ink** statement or test.
4. **Fabric weight as produced**, in writing.
5. **Tracking information.** Not part of the certificate, but required on the garment: add a production date or batch code and place of production to each unit, then put the same batch code in section 1.
6. **Factory city** for section 5.
