# PM baseline verification checklist

Read this before relying on [the onboarding baseline](baseline.md) or [the gap list](gaps-and-needs.md). Retrieve the latest owner handoff from the private JSO workspace or ask for it in the PM session. Record the source and time of each live check in the private workspace.

| Workstream | Verification before using the baseline |
| --- | --- |
| Shopify orders | Check current orders, payments, line items, refunds and fulfillment. Separate paid apparel, other merchandise, rewards, and zero-dollar orders. |
| Inventory and catalog | Export current component stock by SKU and location. Reconcile it with receiving and a physical count. Use current Admin prices and check the shopper-facing availability and shipping promise. |
| Product documentation | Ask the compliance lead for the records applicable to the received products and lots. Escalate unresolved items under the operating charter. |
| Klaviyo | Read actual message and form status. Check for duplicate drafts and validate the audience and checkout experience before proposing a send. |
| Backers and creators | Reconcile the private trackers against carrier scans, order records, refunds, and direct communications. |
| Storefront and planning | Check the latest founder-approved draft-theme work, supplier decisions, recurring costs, and upcoming commitments in their existing trackers before creating tasks. |

Keep operational figures, order details, correspondence, and underlying evidence in the private workspace. Use the existing approval process in [the operating charter](../CLAUDE.md).
